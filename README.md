# 🚀 Featured Projects

## 🏠 Data-Driven Real Estate Valuation & Market Intelligence System

🤖 A Machine Learning-based system designed to predict real estate prices and analyze market trends.

### 🔧 Technologies Used

`Python` • `Streamlit` • `Scikit-learn` • `XGBoost` • `Random Forest` • `ARIMA` • `LSTM` • `Pandas`

### ✨ Features

- 🏠 Predicts property prices using location, area, and amenities.
- 📊 Uses Random Forest and XGBoost for price prediction.
- 📈 Forecasts market trends and demand patterns using ARIMA and LSTM.
- 💰 Calculates investment metrics such as ROI and Rental Yield.
- 🖥️ Provides an interactive Streamlit dashboard.
